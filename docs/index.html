Google Meet Recorder (Video + .vtt)

Record a Google Meet tab. Keep the video. Keep the captions. Keep it on your machine.

Download latest release View on GitHub Full README

What you get

  • Meet-Recording-….webm — tab video + audio, captured locally
  • Meet-Transcript-….vtt — text from Meet’s live captions (CC)
This extension does not run its own speech-to-text. Captions come from Google Meet CC on the page; we save them. The video is yours, recorded in Chrome.

Install in 30 seconds

  1. Download the latest release zip and unzip it
  2. Open chrome://extensions → enable Developer mode
  3. Load unpacked → select the unzipped folder
  4. Join Meet, turn on CC, hit Start Recording
Want a .vtt? Turn captions on before you start. No CC on screen means video only.
